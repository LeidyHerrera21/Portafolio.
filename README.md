# 🌟 Portafolio Personal — Leidy Herrera

Bienvenido a mi repositorio principal. Este proyecto alberga mi portafolio web interactivo, diseñado para mostrar mi trayectoria profesional, proyectos desarrollados, habilidades técnicas y certificaciones en el campo de la **Ingeniería de Software con IA** y el **Desarrollo Web**.

---

## 🚀 Demo e Información General

* **👤 Autora:** Leidy Herrera Ramírez
* **🎓 Perfil:** Ingeniera de Software con IA / Desarrolladora Web

---

## 🛠️ Tecnologías Utilizadas

El proyecto combina un desarrollo web nativo enfocado en diseño interactivo y rendimiento, junto con librerías modernas integradas en la estructura:

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **Frameworks & Estilos:** Bootstrap, UI Components (Radix UI)
* **Tipografías:** Google Fonts (*Cormorant*, *Monsieur La Doulaise*, *Tenor Sans*)
* **Iconos & Recursos:** Devicon, SVG personalizado
* **Servicios / Backend:** Firebase Cloud Firestore
* **Herramientas de Build & Dependencias:** Node.js, Next.js, Tailwind CSS, PostCSS, Lucide React

---

## 📂 Proyectos Destacados en el Portafolio

1. **Space-Dodger:** Juego dinámico de esquivar obstáculos construido con HTML, CSS y JS puro.
2. **Doctor Strange:** Proyecto de *Creative Coding* que simula los efectos visuales de portales mágicos.
3. **EcoMarket:** Plataforma de e-commerce sostenible integrada con Firebase Cloud Firestore.
4. **Navidad y Año Nuevo:** Experiencia interactiva con árbol 3D, efectos de nieve y música.
5. **Cifrador Césars:** Herramienta interactiva de encriptación basada en el cifrado César.
6. **Sitios Web Temáticos & Fanfiction:** Platas e iteraciones como *Un Misterio Mortal*, *Mi vida con los Sakamaki*, *En Busca de los Creepypastas*, entre otros.

---

## ⚡ Características Principales

* **Diseño Responsive & UI Adaptativa:** Navegación optimizada para dispositivos móviles mediante menú tipo hamburguesa y diseño adaptativo.
* **Filtro de Proyectos Interactivos:** Selección dinámica para filtrar proyectos entre *Todos*, *Completados* y *En Curso*.
* **Tarjeta Interactiva Flip 3D:** Efectos de animación al interactuar con el perfil.
* **Panel de Habilidades y Certificados:** Selector multinivel para explorar rápidamente las tecnologías dominadas (*Java, Python, Oracle, Linux, Git, etc.*) y diplomas obtenidos.
* **Efectos Visuales Avanzados:** Integración de gradientes dinámicos, desenfoques por GPU y tipografías estilizadas.
